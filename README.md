# 🔦 Linterna

Una página web con una linterna animada en el centro de la pantalla. Un solo control: el botón del centro enciende y apaga la luz.

## Características

- Linterna dibujada en SVG, sin imágenes ni dependencias.
- Haz de luz con parpadeo al encender, vaivén suave y partículas de polvo.
- Un único botón (también funciona con teclado: `Tab` + `Enter`/`Espacio`).
- Adaptable a móviles y escritorio.
- Respeta `prefers-reduced-motion`.

## Uso

Abre `index.html` en tu navegador. No requiere instalación ni compilación.

## Publicar en GitHub Pages

1. Sube el repositorio a GitHub.
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. Tu linterna quedará disponible en `https://<usuario>.github.io/<repositorio>/`.

## Estructura

```
index.html   Estructura y linterna (SVG)
style.css    Estilos y animaciones
script.js    Lógica del botón y partículas
```
